# Authors and citations

The OCaml project originated as a CS 3110 Spring 2026 project by James Cenawood
(JCC463), Orion Hoch (OGH6), Emily Wei (EJW235), and Max Masleyev (MAM759).

## Citations

- **Source material:** the Drop the Handkerchief game is adapted from the
  *Surpassing the Leader* arc of *Usogui* by Toshio Sako.
- **Notty:** terminal rendering uses
  [`notty`](https://github.com/pqwy/notty) by David Kaloper Meršinjak (ISC).
- **Alcotest:** tests use [`alcotest`](https://github.com/mirage/alcotest) (ISC).
- **Dune:** the build uses [`dune`](https://github.com/ocaml/dune) (MIT).

The current subtree is an independent pure-DTH reference. It does not claim the
STL-only leap-window mechanics.
