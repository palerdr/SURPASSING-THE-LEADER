## Citations

- **Source material.** The game's rules, characters (Baku Madarame, Hal/Kiruma Souichi), and strategic structure are adapted from the *Surpassing The Leader* arc of the manga *Usogui* by Toshio Sako. All design decisions in this project — leap-second routing, cylinder mechanics, role rotation, the "Drop The Handkerchief" framing — derive from that arc.
- **Notty.** Terminal UI rendering uses [`notty`](https://github.com/pqwy/notty) by David Kaloper Meršinjak (ISC license).
- **Alcotest.** Testing framework: [`alcotest`](https://github.com/mirage/alcotest) (ISC license).
- **Dune.** Build system: [`dune`](https://github.com/ocaml/dune) (MIT license).
